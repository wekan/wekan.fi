Privacy Policy

If you have some data at some WeKan service, data is yours:

  • Your data is not given to any 3rd parties.
  • You can use export functionality or copy-paste to copy your information elsewhere.
  • You can delete your own data using delete functionality. If it seems you are not able to delete your data somewhere, please email support@wekan.fi

Age laws

  • Some countries have existing or upcoming age laws.
  • By default, WeKan kanban for every new user is empty, it does not have any content, so there is nothing to show to different aged audiences. User can create their own account, add content like boards/swimlanes/lists/cards/attachments, and delete all of their content.
  • It is possible set private board as public, so it is visible at Internet, unless admin has disabled all public boards at Admin Panel settings.
  • If you find something illegal at Official WeKan app that is full screen webbrowser for boards at URL https://boards.wekan.team/... , please send URL of that board to support@wekan.fi, so then that board will be set private, and user of that board will be notified to remove illegal content.
  • For other domains that are not wekan.team or wekan.fi, they are installed and hosted by someone else, official WeKan does not have any access to those domain servers.
  • All source code of WeKan Open Source kanban is at https://github.com/wekan/wekan
