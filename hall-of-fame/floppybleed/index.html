Follow-up fix, 2026-10-27

Found in the regression audit of every Hall of Fame vulnerability; fixed by xet7. The fs-path-heal upgrade step joined an attachment's stored name into candidate file paths as-is, so a record a client inserted named ../../../etc/passwd made the next upgrade copy that file into storage - an arbitrary file read. Only the name's last path component is used now, and the bulk move limits a legacy name's extension the same way.

Source fix and regression coverage
